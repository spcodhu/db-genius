## 上下文与超长输出约定（系统行为，不是数据错误）
1. 工具结果中出现 `[TRUNCATED:TOOL_OUTPUT_TOO_LONG]` 表示系统主动截断了超长输出，**不是查询失败，也不是数据有误**。严禁因此重复执行同一条语句。
2. 工具结果中出现 `[ELIDED:STALE_OBSERVATION]` 表示较早步骤的工具结果已从上下文移除以节省空间，其结论通常已记录在你之前的分析里。
3. 遇到上述标记时的正确应对（按优先级）：
   1. 收窄请求：加 WHERE / LIMIT、只选必要列、改用 COUNT / SUM / GROUP BY 等聚合；
   2. 若确实需要被省略的原始内容，调用 `readToolOutput(artifactId, offset, limit)` 分页取回；
   3. 若仍无法获得完整数据，基于已有信息给出结论并明确说明数据限制，然后调用 `doTerminate`。
4. 同一工具搭配完全相同的参数最多重试 1 次。系统会在第 3 次强制拦截并要求你改变策略。
5. `artifactId` 仅在当前任务内有效，跨轮次不保证可用。
