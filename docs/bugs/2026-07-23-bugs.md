# 2026-07-23 Bugs

## 1. AI 对话记不住上下文（已修复 2026-07-26）

**现象**：在页面上和 AI 对话时，AI 记不住上一次会话的内容，不新开会话也记不住，每次输入都像是新开了一个。

**根因（两个叠加的问题）**：

1. **前端从未保存 conversationId**：`src/stores/chat.ts` 的 `currentConversationId` 从未被赋过非 null 值，且后端 SSE 协议里没有回传会话 id 的通道。导致每个请求的 `conversationId` 都是 null，后端每条消息新建一行 conversation（既丢上下文又产生孤儿数据）。
2. **后端历史不传给真正回答的 LLM 调用**：`IntentRouter` 加载的最近历史只用于意图分类；`SimpleChatHandler` 裸调 `chatClient.prompt().user(msg)`，三个工具 Agent（DbSql/DbWorkflow/DbCompare）每请求新建实例、`messageList` 从空开始。

**修复**：

- 后端：4 个 intent handler 在 `getOrCreateConversation` 后推送 `"conversation"` SSE 事件回传会话 id；`SimpleChatHandler` 在落库当前消息前加载最近 10 条历史并通过 `.messages()` 注入；`BaseAgent` 新增 `setHistoryMessages`，`ToolCallAgent.onStepStart` 预填历史，三个工具 handler 加载历史后注入 Agent。
- 前端：`SseEventType` 增加 `conversation` 类型，`handleSseEvent` 保存 `currentConversationId`；`ConversationsPage` 新增「继续对话」入口（加载历史消息进 store 并跳转聊天页）。

**遗留事项**：修复前数据库里积累的孤儿 conversation 行（每条消息一行）可手动清理。
